About the platform
Purpose, workflow & responsible use

Purpose

AQACT helps researchers, environmental officers, policy makers, and journalists turn sensor data into understandable air-quality evidence. It supports data cleaning, exploration, visualization, compliance screening, and model-based analysis while keeping data and computation local by default.

Typical Workflow

  1. Upload data
  2. Validate inputs
  3. Explore datasets
  4. Generate analyses
  5. Create visualizations
  6. Export insights

Analysis Scope

Data: provider-aware cleaning, mapping, missing values, resampling, and export.

Statistics: descriptive metrics, trends, seasonal profiles, extremes, exceedances, correlations, and uncertainty views.

Models & compliance: anomaly detection, supervised models, model evaluation, and WHO / country EPA screening.

Responsible Use

Compliance results are screening evidence, not a legal determination. Confirm the applicable standard, units, averaging period, calibration, siting, and data completeness with the responsible authority before enforcement, public alerts, or publication. Sensor data contain assumptions and uncertainty; interpret findings in context and never substitute model output for validated regulatory monitoring.

This platform is not for sale in any form. It is intended solely for research, educational, and scientific air-quality data analysis purposes.
